The four and final exam is similar to the programming parts of the first two exams. It serves as a chance to show that you have learned how to apply all of the core data-science concepts for visualization and manipulating data through the Python libraries that we have learned. Combined with the data creation task in Exam 3 and the end-to-end analysis in the final project, you will have demonstrated your ability to do all of the core tasks that we expect from students in DSST289.

I will not be indicating the exact questions this time around as almost all of the functions you have seen and practiced with for over a month. However, I will this time tell you the datasets ahead of time: we'll be writing code for the curling dataset that is the subject of your final project. As usual, I will provide the first few rows of each table so you have the names and formats at hand.

Below is an exhaustive list of the functions that you need to be able to apply during the exam. It is also a good reminder of the topics that you should be able to use in the future.

  1. Functions for plotting: ggplot(), aes(), geom_point() and geom_text(). You should also know how to use reorder(). No need to remember other functions for scales, labels, or other geometry types.
  2. How to use .loc[] to select rows and columns from a dataset.
  3. The following methods attached to a DataFrame object: query(), eval(), groupby(), agg(), reset_index(), merge() and sort_values().
  4. For agg() you should know the following aggregation functions: "mean", "min", "sum", "first".
  5. For merge() you should by able to use the function with both `on=` (when the key name(s) match) as well as `left_on` and `right_on`.

You will not need to memorize the modeling functions, the pivot/melt methods, or be able to apply more complex lambda functions or aggregations.

Review Questions

All of the questions refer to the datasets from Exam 02.

1. Compute total amount of salt in each recipe.

(
  ingredients
  .merge(food, left_on="item", right_on="food")
  .eval("salt_amt = salt * (amount / 100)")
  .groupby("recipe")
  .agg(
    salt_amt = ("salt_amt", "sum")
  )
  .reset_index()
)

2. Compute total time of each recipe and sort from shortest to longest.

(
  steps
  .groupby("recipe")
  .agg(
    time = ("time", "sum")
  )
  .reset_index()
  .sort_values("time")
)

3. Compute the largest amount of an ingredient included in each recipe.

(
  ingredients
  .groupby("recipe")
  .agg(
    amount = ("amount", "max")
  )
  .reset_index()
)

4. Plot recipe name with time on the x-axis and number of steps on the y-axis.

temp = (
  steps
  .groupby("recipe")
  .agg(
    time = ("time", "sum"),
    steps = ("instructions", "count")
  )
  .reset_index()
)

(
  ggplot(temp, aes("time", "steps"))
  + geom_text(aes(label = "recipe"))
)
