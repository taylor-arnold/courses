Exam I Study Guide

The first exam consists of 15 questions. All involve hand-writing short code blocks concerning the food dataset, which has one row for each food item and columns including item, food_group, calories, total_fat, sat_fat, cholesterol, sodium, carbs, fiber, sugar, protein, iron, vitamin_a, vitamin_c, and color. You should generally be comfortable with the material in Chapter 1, Chapter 2, and Chapter 3, but only the following will be needed for the exam:

  1. Reading a dataset into Python with pl.read_csv, and identifying the observations and variables of a table.
  2. Using .sort to sort the data by one or more columns, in ascending or descending order.
  3. Selecting a certain number of rows using .head or .tail.
  4. Using .select to choose a subset of the columns, or .drop to remove them.
  5. Selecting rows using .filter based on a numeric variable being less than, less than or equal to, equal to, greater than or equal to, or greater than a fixed value.
  6. Selecting rows using .filter based on a string variable being equal to a specific value.
  7. Selecting rows using .filter and .is_in to select rows where a string column is in a set of values.
  8. Combining two or more conditions inside .filter with the & (and) and | (or) operators, wrapping each condition in its own set of parentheses.
  9. Using .with_columns to create a new variable based on arithmetic manipulation of two or more other columns.
  10. Using .with_columns to create a new variable based on applying a mathematical method (such as the logarithm; I will give you the name of the method) to one of the columns.
  11. Using .rename to change the name of a column, and .unique to return one row for each value of a column.
  12. Using pl.when().then().otherwise() inside of .with_columns to build an indicator variable from a condition.
  13. Naming the four core data types (str, i64, f64, and bool) and saying which one you would expect a given column to have.
  14. Using .cast to convert a column to another type, including the use of strict=False when some values cannot be converted.
  15. Handling missing values with .drop_nulls, .fill_null, and .is_null, and explaining the difference between a null and a NaN.
  16. Applying a string method (such as .str.to_uppercase; I will give you the name of the method) to a text column.
  17. Explaining, in a sentence or two, what an expression is and what it means for a method such as .filter to act as a context for it.

Many questions will require putting multiple functions together in a method chain. All can be done with at most three methods. Your code should follow the class formatting rules of putting parentheses around the whole block, starting with the DataFrame, and having each method on its own line. You should be familiar with the other formatting rules regarding spacing and names, but these will not be graded on the exam.

Practice Exam Questions and Answers

The questions below use a different dataset, movie, which has one row for each film with the columns year, title, mpa, runtime (in minutes), gross (in millions of dollars), rating_count, rating, and metacritic. The skills are exactly the ones you will need for the food data on the exam.

1. Return the five films with the highest rating.

(
    movie
    .sort(c.rating, descending=True)
    .head(n=5)
)

2. Select only the films that are rated "R" and that run longer than two hours.

(
    movie
    .filter((c.mpa == "R") & (c.runtime > 120))
)

3. Keep only the films whose MPA rating is "G", "PG", or "PG-13", and return just the title and the MPA rating.

(
    movie
    .filter(c.mpa.is_in(["G", "PG", "PG-13"]))
    .select(c.title, c.mpa)
)

4. Create a new column giving the amount of money each film made per minute of its runtime.

(
    movie
    .with_columns(
        gross_per_min = c.gross / c.runtime
    )
)

5. Create a new column holding the base-ten logarithm of the number of ratings, and then sort the films from the largest value of this new column to the smallest.

(
    movie
    .with_columns(
        log_count = c.rating_count.log10()
    )
    .sort(c.log_count, descending=True)
)

6. Return one row for each distinct MPA rating in the data.

(
    movie
    .unique(subset=["mpa"])
)

7. Change the name of the column gross to gross_millions.

(
    movie
    .rename({"gross": "gross_millions"})
)

8. Create a new column named blockbuster that is equal to 1 for films that made more than 200 million dollars and 0 for every other film.

(
    movie
    .with_columns(
        blockbuster = pl.when(c.gross > 200).then(1).otherwise(0)
    )
)

9. Pretend that the metacritic column was read into Python as a string, because the films that were never reviewed have their score recorded as "n/a". Create a column named meta_num holding the score as an integer, with anything that cannot be converted turned into a missing value.

(
    movie
    .with_columns(
        meta_num = c.metacritic.cast(pl.Int64, strict=False)
    )
)

10. Create a new column holding the title of each film in uppercase letters, keeping all of the other columns as they are.

(
    movie
    .with_columns(
        title_upper = c.title.str.to_uppercase()
    )
)

11. What is printed if you type c.rating > 8 into a cell on its own, with no DataFrame anywhere in sight?

Not a column of True and False values, and not an error. Polars prints a
description of an expression: a recipe that says "take the column named
rating and compare each value to 8." No data is attached to it, because
`c.rating > 8` does not know that `movie` exists. The expression only
produces values once it is handed to a context, such as `.filter()`,
which keeps the rows where it comes out True, or `.select()`, which
returns the True and False values themselves as a new bool column.
