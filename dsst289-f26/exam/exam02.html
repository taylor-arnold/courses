Exam II Study Guide

[← back]

The second exam consists of 15 questions. All involve hand-writing short code blocks concerning the RVA flights dataset rva, which has one row for each flight leaving or arriving at Richmond International Airport, with the columns year, month, day, dep_time, sched_dep_time, dep_delay, arr_time, sched_arr_time, arr_delay, carrier, flight, tailnum, origin, dest, air_time, and distance. It is very similar in style to Exam I. You should generally be comfortable with the material in Chapter 4, Chapter 5, and Chapter 6. However, only those items mentioned below, along with everything listed on Exam I, will be required for this exam.

  1. Building a plot by starting a chain from a dataset with .ggplot(aes(...)) and then adding geometries as further methods in the chain.
  2. Creating a scatterplot with geom_point, which may have a variable or a fixed color or size.
  3. Adding text to a plot with geom_text, which may have a variable or a fixed color or size. No need to build in nudging (it is not possible without seeing the full dataset to get the scale correct anyway).
  4. Creating a line plot with geom_line, most often with a unit of time on the horizontal axis, and with an optional color aesthetic to draw one line per group.
  5. Creating a bar plot with geom_col from a numeric column you have already computed, together with coord_flip to run the bars horizontally.
  6. Knowing where a fixed aesthetic goes (outside of aes, but inside the geometry) versus a variable aesthetic (inside a call to aes), and being able to explain the difference.
  7. Using .group_by along with .agg to summarize one or more variables with .mean, .median, .min, .max, .sum, .first, or .last. You should also be able to add a count by including pl.len(), and to return the groups in a predictable order with maintain_order=True.
  8. Grouping by more than one column at a time.
  9. Aggregating an expression rather than a bare column, such as counting the flights delayed more than thirty minutes with (c.dep_delay > 30).sum().
  10. Knowing the difference between pl.len(), .count(), and .n_unique(), and being able to say which one a given question calls for.
  11. Summarizing an entire dataset in a single row using the aggregation syntax inside .select, and explaining why .agg cannot be used for this.
  12. Using .group_by to apply .head or .tail to select a certain number of rows from each group, after an appropriate .sort.
  13. Using .over inside of .with_columns to attach a group-level number to every row, and inside of .filter to compare each row against its own group.
  14. Using the ordered methods .shift, .rank, and .cum_sum, including scoping them to a group with .over, and knowing why the .sort that comes before them matters.
  15. Smoothing a column with .rolling_mean(window_size=<int>), and saying which rows come back as missing values and why.
  16. Deciding whether a given question is answered by .group_by with .agg or by .over, and explaining the choice in a sentence.
  17. We will not have histograms, boxplots, density plots, bar plots that do their own counting, lines of best fit, scales, facets, or labels on this exam. Those all come from Chapter 7 and will appear on Exam III.

Many questions will require putting multiple functions together in a method chain. All can be done with at most three data methods and three graphics methods. Your code should follow the class formatting rules of putting parentheses around the whole block, starting with the DataFrame, and having each method on its own line. You should be familiar with the other formatting rules regarding spacing and names, but these will not be graded on the exam.

Practice Exam Questions and Answers

The questions below use the movie dataset from the first study guide, which has one row for each film with the columns year, title, mpa, runtime, gross, rating_count, rating, and metacritic.

1. Compute the average runtime of the films by year. Include a count of the number of films in each year in the output table.

(
    movie
    .group_by(c.year, maintain_order=True)
    .agg(
        avg_runtime = c.runtime.mean(),
        count = pl.len()
    )
)

2. Create a scatterplot where the points are years, where the x-axis gives the average rating, the y-axis the average gross (amount of money it made), and all the points are in the color "yellow".

(
    movie
    .group_by(c.year)
    .agg(
        avg_rating = c.rating.mean(),
        avg_gross = c.gross.mean()
    )
    .ggplot(aes(c.avg_rating, c.avg_gross))
    .geom_point(color="yellow")
)

3. Create a text plot with the films from the year of your birth, with rating on the x-axis and gross on the y-axis, and the label given by the film title.

(
    movie
    .filter(c.year == 1985)
    .ggplot(aes(c.rating, c.gross))
    .geom_text(aes(label=c.title))
)

4. Create a line plot showing how the average gross of a film has changed over time, with one line for each MPA rating.

(
    movie
    .group_by(c.year, c.mpa)
    .agg(avg_gross = c.gross.mean())
    .sort(c.year)
    .ggplot(aes(c.year, c.avg_gross))
    .geom_line(aes(color=c.mpa))
)

5. Create a horizontal bar plot showing the number of films with each MPA rating.

(
    movie
    .group_by(c.mpa)
    .agg(count = pl.len())
    .ggplot(aes(c.mpa, c.count))
    .geom_col()
    .coord_flip()
)

6. For each MPA rating, count the number of films that have a rating above 8, without adding any new columns to the dataset first.

(
    movie
    .group_by(c.mpa, maintain_order=True)
    .agg(
        n_great = (c.rating > 8).sum()
    )
)

7. Return the single highest-rated film in each year.

(
    movie
    .sort(c.rating, descending=True)
    .group_by(c.year)
    .head(n=1)
)

8. Summarize the whole dataset in a single row, giving the total gross of every film, the average rating, and the number of films.

# We cannot use .agg here, because in Polars .agg always belongs to a
# .group_by. The same aggregation syntax inside .select collapses the
# entire frame to a single row.
(
    movie
    .select(
        gross_total = c.gross.sum(),
        avg_rating = c.rating.mean(),
        n = pl.len()
    )
)

9. Add a column to the data giving each film's rating minus the average rating of all the films released in the same year, keeping every film in the result.

(
    movie
    .with_columns(
        rating_diff = c.rating - c.rating.mean().over(c.year)
    )
)

10. Keep only the films whose gross is above the median gross of the films released in the same year, without adding any new columns to the dataset.

(
    movie
    .filter(c.gross > c.gross.median().over(c.year))
)

11. Add a column giving each film's rank by gross within its own year, with a rank of one going to the film that made the most money.

(
    movie
    .with_columns(
        gross_rank = c.gross.rank(descending=True).over(c.year)
    )
)

12. Compute the average gross of the films in each year, and then add a column giving the change in that average from the previous year.

(
    movie
    .group_by(c.year)
    .agg(avg_gross = c.gross.mean())
    .sort(c.year)
    .with_columns(
        change = c.avg_gross - c.avg_gross.shift(1)
    )
)

13. Sort the films from the highest gross to the lowest and compute, for each film, the percentage of all the money made by every film in the dataset that is accounted for by that film and everyone above it.

# Note the two sums doing different jobs: .cum_sum() is a running total
# that changes on every row, while .sum() is the fixed total of the
# whole column.
(
    movie
    .sort(c.gross, descending=True)
    .select(
        c.title,
        c.gross,
        cum_share = c.gross.cum_sum() / c.gross.sum() * 100
    )
)

14. Compute the average rating of the films in each year, and then add a smoothed version of it, given by the average of that year and the four years before it. Which rows come back as missing values?

# The first four rows are null: they do not yet have a full window of
# five years behind them.
(
    movie
    .group_by(c.year)
    .agg(avg_rating = c.rating.mean())
    .sort(c.year)
    .with_columns(
        smooth = c.avg_rating.rolling_mean(window_size=5)
    )
)
