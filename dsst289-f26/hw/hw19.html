As in the previous homework, assume you have a dataset called students, with columns named name, major, year, gpa, and study_hours, and a dataset called majors, with columns named major, department, and n_faculty. Hand write the following.

  1. A colleague has sent you a new version of the majors table, and you are not certain that it contains only one row per major. Write the single line of code that would tell you, before you join anything, whether major is a genuine primary key of that table. Then describe what would happen to the result of the join in part (2) of the previous homework if it is not, and explain why Python would not raise an error to tell you about it.
  2. The code that builds two new datasets from students: history, holding the name and GPA of each History major, and music, holding the name and GPA of each Music major, each sorted by GPA and with any missing GPAs removed.
  3. The code that matches each History major with the Music major whose GPA is closest to their own, keeping both GPAs in the result, along with a sentence explaining why part (2) had to sort the two tables first.
  4. The code that returns every pair of a History major and a Music major whose GPAs differ by less than 0.1, along with a sentence explaining why this kind of join is slower than the one in part (3).
  5. The code that adds to students a column holding the average GPA of the student's major, written two different ways: once using the tool from the window functions chapter, and once by building a summary table and joining it back. Then give a sentence describing a situation in which you would prefer each version.
