As in the previous homework, assume you have a dataset loaded into Python called students, with columns named name, major, year, gpa, and study_hours. Every plot below builds on the same scatter plot of study_hours and gpa. Hand write the following.

  1. The code that produces this scatter plot with the color of each point determined by the student's major, using the color palette that the reading recommends for readers who are color-blind, followed by a second version that instead assigns a specific color of your own choosing to each of three majors.
  2. The code that produces the scatter plot with grid lines and labels every five hours along the horizontal axis and with the vertical axis pinned to start at zero.
  3. The code that splits the scatter plot into a grid of small panels, one for each major, with the points colored by major and the legend hidden.
  4. The code that adds a full set of labels to the scatter plot: a description of each axis, a title, a subtitle, and a caption naming where the data came from, along with a sentence explaining why we have not bothered to do this for any of the plots we have made so far.
  5. For each of the two questions below, name the plot you would use and explain your choice in a sentence: (a) how are the study hours of the class distributed, and (b) do students in some majors have higher GPAs than students in others? Then name the one guideline from the list at the end of the reading that you think is most often broken in the plots you have seen elsewhere, and say why.

Solutions

1. Color the points by major using the palette the reading recommends for color-blind readers, then write a version with a color of your choice for each of three majors.

(
    students
    .ggplot(aes(c.study_hours, c.gpa))
    .geom_point(aes(color=c.major))
    .scale_color_cmap_d()
)

(
    students
    .ggplot(aes(c.study_hours, c.gpa))
    .geom_point(aes(color=c.major))
    .scale_color_manual(values={
        "Biology": "navy",
        "Economics": "darkorange",
        "History": "seagreen"
    })
)

The recommended palette is viridis, which runs from dark purple through green to yellow. It is already the default for a categorical color, so .scale_color_cmap_d() names that choice without changing the plot. Leaving the scale out entirely is also correct. The homework does not name the three majors, so the ones above are placeholders. The keys in values have to match the values in the major column exactly, and any color name that plotnine knows will work.

2. Put grid lines and labels every five hours on the horizontal axis and start the vertical axis at zero.

(
    students
    .ggplot(aes(c.study_hours, c.gpa))
    .geom_point()
    .scale_x_continuous(breaks=breaks_width(5))
    .scale_y_continuous(limits=(0, None))
)

breaks_width comes from mizani.breaks, which the reading imports in its setup. The None in limits leaves the top of the vertical axis at its default.

3. Split the scatter plot into one panel per major, with points colored by major and no legend.

(
    students
    .ggplot(aes(c.study_hours, c.gpa))
    .geom_point(aes(color=c.major), show_legend=False)
    .facet_wrap("major")
)

The legend can go because each panel is already labeled with its major. The panels share the same axes by default, which lets you compare the majors at a glance.

4. Add axis labels, a title, a subtitle, and a caption, and explain why we have not labeled earlier plots.

(
    students
    .ggplot(aes(c.study_hours, c.gpa))
    .geom_point()
    .labs(
        x="Hours Spent Studying per Week",
        y="Grade Point Average (GPA)",
        title="Relationship between Study Time and GPA",
        subtitle="All students in the class",
        caption="Data from the class survey"
    )
)

The wording of the labels is up to you, and the caption should name wherever your data came from. We have not labeled earlier plots because they were for exploring the data. Default labels take no effort, so it is easy to try a different variable or setting without relabeling anything. They also show the exact column names, which are the names you need when you write the next piece of code. Full labels are worth adding once a plot is going to someone else.

5. Choose a plot for each of two questions and explain the choice, then name the guideline from the end of the reading that you see broken most often.

(a) A histogram of study_hours. The question is about the
distribution of a single numeric variable, and a histogram shows how
many students fall into each range of hours. A density plot is also
a good answer.

(b) A boxplot of gpa for each major. This question is about the
relationship between a categorical variable and a numeric one, and a
boxplot puts the median and spread of each major side by side.
Sorting the majors by their median GPA makes the comparison easier.

The guideline has no single correct answer. A strong response names
one guideline from the list and explains why, ideally with a kind of
plot or a specific example the student has seen, such as a news graphic
or a report at work. One possible example: "Use color and shape only
with a small set of categories." Line charts in the news often give
each of a dozen or more countries its own color, so several of the
lines look alike and the reader has to keep checking the legend.
