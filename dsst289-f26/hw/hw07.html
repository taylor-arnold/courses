Homework 07

[← back]

Assume you have three datasets loaded into Python. The first, students, has one row for each student in the class, with columns named name, major, year, gpa, and study_hours. The second, semesters, has one row for each student in each semester they have been enrolled, with columns named name, semester, and gpa. The third, majors, has one row for each major, with columns named major and n_students. Hand write the following.

  1. The code that produces a scatter plot of study_hours and gpa in which the color of each point is determined by the student's major.
  2. The code that produces the same scatter plot with every point drawn in a single fixed color of your choosing, followed by a sentence explaining why the color is written in a different place in parts (1) and (2).
  3. The code that produces a scatter plot of study_hours and gpa in which all of the points are drawn faintly, and only the History majors are additionally labelled on the plot with the student's name, in a color of your choosing and in a smaller font nudged slightly above the point.
  4. The code that uses semesters to produce a line plot showing how each student's GPA has changed over time, with one line per student.
  5. The code that uses majors to produce a bar plot of the number of students in each major, with the bars running horizontally.

Solutions

1. Make a scatter plot of study_hours and gpa with the points colored by major.

(
    students
    .ggplot(aes(c.study_hours, c.gpa))
    .geom_point(aes(color=c.major))
)

The x and y aesthetics stay in .ggplot(). The color mapping goes in its own aes() inside .geom_point(), which is the convention the reading uses for every aesthetic other than x and y. plotnine picks a color for each major and adds a legend on the right.

2. Make the same plot with every point in one fixed color, and explain why the color moved.

(
    students
    .ggplot(aes(c.study_hours, c.gpa))
    .geom_point(color="#F5276C")
)

Any color works here, either a hex code or a name such as "red". In part (1) the color changes from point to point according to a column of the data, so it is a mapping and belongs inside aes(). In part (2) the color is one value that is the same for every point and has nothing to do with the data, so it goes outside aes() but still inside .geom_point(). Check that your sentence makes this distinction between a variable aesthetic and a fixed one. Also check that you did not write aes(color="#F5276C"), which treats the string as data and does not give you that color.

3. Draw all of the points faintly and label only the History majors with their names.

history = (
    students
    .filter(c.major == "History")
)
(
    students
    .ggplot(aes(c.study_hours, c.gpa))
    .geom_point(alpha=0.2)
    .geom_text(
        aes(label=c.name),
        color="#F5276C",
        size=6,
        nudge_y=0.05,
        data=history
    )
)

The exact numbers and the color are yours to choose, but the answer needs all of these pieces:

  - A second dataset holding only the History majors, made with
    .filter() and saved under a name before the plot.

  - The full students table at the start of the plot, so that the point
    layer draws everyone. If you filter before .ggplot(), as in
    Homework 06, the other majors vanish from the plot.

  - A fixed alpha between 0 and 1 in .geom_point() to make the points
    faint. It sits outside aes() for the same reason as the color in
    part (2).

  - A .geom_text() layer with label=c.name inside aes(), because the
    label comes from a column.

  - The fixed color, size, and nudge_y outside aes(), and data=history
    so that only this one layer uses the smaller table.

Pick a nudge_y that fits the scale of the y-axis. It is measured in GPA points, so the 0.5 used in the reading would push the labels far away from their points; something near 0.05 is about right. The reading also draws the highlighted points a second time in color with .geom_point(color="#F5276C", data=history). The question does not ask for that layer, but it is fine to include it.

4. Use semesters to make a line plot of each student's GPA over time, with one line per student.

(
    semesters
    .ggplot(aes(c.semester, c.gpa))
    .geom_line(aes(group=c.name))
)

Two answers work here. The group aesthetic splits the rows into one line per student without changing the color, which suits a whole class of students. Writing aes(color=c.name) also gives one line per student, as in the cellphone example from the reading. It adds a legend, which gets crowded once there are more than a handful of names. Time goes on the x-axis in either version. With neither group nor color, plotnine has no way to tell which rows belong to the same student, so it cannot draw a separate line for each one.

5. Use majors to make a horizontal bar plot of the number of students in each major.

(
    majors
    .ggplot(aes(c.major, c.n_students))
    .geom_col()
    .coord_flip()
)

The categorical column still goes first and the numeric column second, exactly as for vertical bars. The .coord_flip() layer is what turns the bars on their side, so do not swap the two columns inside aes() as well. The question does not ask for an order, but adding .sort(c.n_students) before .ggplot(), as the reading does, ranks the bars from the smallest major to the largest.
