On a sheet of paper, hand write a small tabular dataset showing the courses you are taking this semester. Include at least four columns, make sure that at least one is numeric and at least one is a string, and give every column a variable name. Then hand write the following.

  1. The number of observations and the number of variables in your dataset.
  2. The code that would read this dataset into Python from a file named "data/courses.csv" and save it as an object called courses.
  3. A corrected version of the line below, rewritten to follow the formatting conventions from the reading, along with a short note naming each convention you had to fix.
x=pl.read_csv('data/courses.csv' ,n_rows=5)

Solutions

The table itself is yours, so questions 1 and 2 depend on what you wrote down. Here is a table of the right shape to check yours against:

course_id   title                   credits   professor
DSST289     Introduction to DS      1.0       Arnold
MATH211     Discrete Structures     1.0       Kerckhove
FREN221     French Conversation     1.0       Ravaux
MUS127      Jazz History            0.5       Bennett

1. How many observations and how many variables are in your table?

4 observations and 4 variables.

One observation per course, so count the data rows and leave out the header. The variables are the columns: course_id, title, credits, and professor. Two things to check on your own page: every column needs a name written at the top, and at least one column has to hold numbers (credits here) while at least one holds text.

2. Read the file into Python and call the result courses.

courses = pl.read_csv("data/courses.csv")

The path is a string, so it needs quotes, and it is relative to where the script lives rather than an address on your own laptop.

3. Rewrite the given line so it follows the formatting conventions, and say what you fixed.

courses = pl.read_csv("data/courses.csv", n_rows=5)

Three fixes:
  1. Spaces around the assignment =, which had none.
  2. Double quotes around the file path instead of single quotes.
  3. A space after the comma, not before it. The original had it
     backwards.

The n_rows=5 is already right and should be left alone. Named arguments are the one place we do not put spaces around the =, so "fixing" it to n_rows = 5 would break the convention rather than follow it. Renaming x to courses is worth doing too, though that is a judgment about clear names rather than one of the spacing rules; x tells a reader nothing about what is in the table.
