Due at Project Workshop II, the last class before presentations. Your collection window closed on Sunday and the weather table is posted. This homework is where you find out whether the dataset you spent two weeks making actually holds together. Export every table, load them into Python, and run the checks below. Bring the code and its output to class, along with the files themselves; the class period is yours to work on the analysis with me in the room.

  1. Load every one of your tables with pl.read_csv. Print the schema of each one and check the type of every column against the data dictionary you wrote in Homework 17. Note every column whose type is not what you expected, and say what went wrong.
  2. For each table, run the primary key check: compare .n_unique() on the key against len() of the table. Report which tables pass. For any that fail, find the duplicated rows and explain how they got there.
  3. For each foreign key in hours, run an anti-join against the table it points to. Every one of these should come back empty. Report any that do not, and say what a row appearing here tells you about your data.
  4. Count how many of the 336 hours of the window are actually present in your hours table, and how many are missing. Then group the missing hours by hour of the day and make a plot of the result. Look at it and say honestly what it shows about when you fail to record.
  5. Join the provided weather table to your hours table. Say whether the row count changed, and explain why an inner join was or was not the right choice here.
  6. Make one plot that takes a first look at each of your research questions, using at least one of the numeric measures you invented. Do not polish them. Bring them to class and we will talk about what to do next.
  7. Finally, a list of every problem the checks above turned up. Collection is over, so you cannot fix any of it by collecting more; you can only decide what to do about it. For each problem, say how you will handle it in the analysis, and write the sentence that will go in your documentation admitting to it.
