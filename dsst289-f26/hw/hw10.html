Assume you have two datasets loaded into Python. The first, students, has one row for each student in the class, with columns named name, major, year, gpa, and study_hours. The second, semesters, has one row for each student in each semester they have been enrolled, with columns named name, semester (a number counting up from one), and gpa. Hand write the following, writing each one as its own chain of methods that follows the formatting conventions from the reading.

  1. The code that adds a column to students giving each student's study hours as a percentage of all of the study hours put in by the students in their major, keeping every student in the result.
  2. The code that adds a column to students holding the average GPA of the student's major, followed by a sentence describing how the shape of this result differs from the table you would get by computing the same averages with .group_by and .agg.
  3. The code that keeps only the students whose GPA is above the median GPA of their own major, without adding any new columns to the dataset.
  4. The code that adds a column to semesters giving the change in each student's GPA from the previous semester, along with a sentence explaining what would go wrong if you left the .over() off, and a sentence explaining which rows of the result come back as missing values and why.
  5. A few students have a semester with no GPA recorded. Write the code that replaces each of those missing values with that student's most recent previously recorded GPA.
