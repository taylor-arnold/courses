Assume you have a dataset loaded into Python called students, with one row for each student in the class and columns named name, major, year, gpa, and study_hours. Hand write the following.

  1. The code that produces a bar plot of the number of students in each major, letting plotnine do the counting for you, with the bars running horizontally and ordered from the most common major to the least.
  2. The code that produces the same plot, but where you compute the counts yourself before any of the plotting code, followed by a sentence explaining the difference between the two geometries you used in parts (1) and (2) and how you decide which one a given task calls for.
  3. The code that produces a histogram of study_hours, choosing a sensible width for the bins, along with a sentence explaining what the height of a single bar of your histogram tells us.
  4. The code that produces a boxplot of the GPAs in each major, with the majors ordered by their GPA, followed by the .group_by and .agg code that would compute by hand the three numbers that make up each box.
  5. The code that produces a scatter plot of study_hours and gpa with a straight line of best fit drawn through the points and no confidence band around it.

Solutions

1. Bar plot of the number of students in each major, counted by plotnine, with horizontal bars ordered from the most common major to the least.

(
    students
    .sort(pl.len().over(c.major))
    .ggplot(aes(c.major))
    .geom_bar(fill="white", color="black")
    .coord_flip()
)

geom_bar counts the rows in each major itself, so the table has no column of counts to sort on. Sorting by pl.len().over(c.major) writes the size of each student's major onto their row and orders the rows by it. The bars follow the order the majors appear in the data. .coord_flip() makes the bars run horizontally and puts the first major at the bottom, so the ascending sort places the most common major at the top. The fill and color are optional.

2. The same plot with the counts computed before plotting, and a sentence on the difference between the two geometries.

(
    students
    .group_by(c.major)
    .agg(pl.len().alias("n"))
    .sort(c.n)
    .ggplot(aes(c.major, c.n))
    .geom_col(fill="white", color="black")
    .coord_flip()
)

geom_bar takes one categorical aesthetic and counts the rows in each category for you. geom_col takes both an x and a y and draws each y value as the height of a bar. Use geom_bar when you want a raw count of rows and the data still has one row per observation. Use geom_col when the number you want to show is already a column in the table, as it is after .group_by and .agg. Here the ordering comes from a plain .sort(c.n), because the count is now a column.

3. Histogram of study_hours with a sensible bin width, and what the height of one bar means.

(
    students
    .ggplot(aes(c.study_hours))
    .geom_histogram(fill="white", color="black", binwidth=2, boundary=0)
)

Several bin widths work here. A good choice depends on the range of the data; if weekly study hours run from about zero to twenty, a width of 2 gives around ten bins. Setting boundary=0 makes the bins start at whole numbers, such as 0 to 2 and 2 to 4, which makes them easy to read. The height of a bar is the number of students whose study hours fall inside that bar's interval. A bar from 4 to 6 with a height of 7 means seven students study between four and six hours.

4. Boxplot of GPA in each major, with the majors ordered by GPA, followed by the code that computes the three numbers behind each box.

(
    students
    .sort(c.gpa.median().over(c.major))
    .ggplot(aes(c.major, c.gpa))
    .geom_boxplot()
    .coord_flip()
)

(
    students
    .group_by(c.major)
    .agg(
        q25 = c.gpa.quantile(0.25),
        q50 = c.gpa.quantile(0.50),
        q75 = c.gpa.quantile(0.75)
    )
    .sort(c.q50)
)

The majors are ordered by their median GPA, which is the line in the middle of each box. Sorting by c.gpa alone would not work, because it would order the majors by their lowest GPA. The box runs from the 25th percentile to the 75th, with the median at the 50th. The .coord_flip() is optional but makes the major names easier to read.

5. Scatter plot of study_hours and gpa with a straight line of best fit and no confidence band.

(
    students
    .ggplot(aes(c.study_hours, c.gpa))
    .geom_point()
    .geom_smooth(method="lm", se=False)
)

method="lm" fits a straight line, and se=False turns off the confidence band. Putting study_hours on the x-axis treats study time as the variable that might explain GPA.
