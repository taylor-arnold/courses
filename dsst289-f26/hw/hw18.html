Assume you have three datasets loaded into Python. The first, students, has one row for each student in the class, with columns named name, major, year, gpa, and study_hours. The second, majors, has one row for each major offered by the university, with columns named major, department, and n_faculty. The third, roommates, has one row for each pair of students who live together, with columns named name and roommate, both of which hold student names. Hand write the following.

  1. A primary key for each of the three datasets, along with a foreign key in roommates and the table whose primary key it refers to.
  2. The code that adds each student's department to the students dataset, along with a sentence explaining which of the two tables you put on the left of the join and why.
  3. Suppose that a few students have declared a major that does not appear in the majors table at all. Describe what the code you wrote in part (2) does with those students, and then write a second version of the code that keeps every student in the result no matter what.
  4. The code that adds two columns to the roommates dataset, one giving the GPA of the student named in name and one giving the GPA of the student named in roommate, with the two columns clearly distinguished from each other.
  5. The code that returns the rows of roommates whose name has no match at all in students, along with a sentence about what such a row would tell you about your data, followed by the code that keeps only the students who have a roommate listed, without adding any new columns to students.
