As in the previous homework, assume you have a dataset loaded into Python called students, with columns named name, major, year, and gpa. Hand write the following, writing each one as its own chain of methods that follows the formatting conventions from the reading.

  1. The code that changes the name of the column gpa to grade_point_average.
  2. The code that returns exactly one row for each major in the dataset.
  3. The code that adds a new column named gpa_100 holding each student's GPA on a 100-point scale (that is, the GPA divided by 4 and multiplied by 100), keeping all of the other columns as they are.
  4. The code that adds a new column named honors that is equal to 1 for students with a GPA of at least 3.5 and 0 for everyone else.
  5. Finally, in a sentence or two of your own words, explain what the .pipe method does and why we would want it when we already have a chain of methods.
