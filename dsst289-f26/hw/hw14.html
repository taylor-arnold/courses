Suppose that we want to record the attendance of the twenty students in our class across the twenty-five times that the class meets this semester. Hand write the following.

  1. Three different ways that this data could be stored as a table. For each one, name the unit of observation, give the number of rows and the number of columns that the finished table would have, and draw a small mock-up of the first few rows and columns, using three students and three class meetings so that the drawing stays manageable.
  2. A primary key for each of your three tables, along with a sentence describing how the primary key of a table is related to its unit of observation.
  3. The three conditions that make a dataset tidy, written in your own words. Then, for each of your three tables, say whether it is tidy for the unit of observation student × meeting, and if it is not, say which condition it breaks and where the missing variable has gone.
  4. A sentence explaining how one of your untidy tables could nevertheless be a perfectly tidy table, if we were interested in a different question, and name a question about attendance for which it would be the better layout.
  5. An example, drawn from data you have actually seen in another class, at a job, or online, of a table that breaks the first tidy-data condition, along with a note about what a tidied version of it would look like.
