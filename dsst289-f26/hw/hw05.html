Assume you have a dataset loaded into Python called students, with columns named name, major, year, gpa, and exam. Hand write the following.

  1. The four core data types described in the reading, along with the column of students that you would expect to have each type.
  2. The exam column was read in as a string because one student who missed the test has a score recorded as "absent". Write the code that adds a new column named exam_score holding the exam scores as integers, with anything that cannot be converted to a number turned into a missing value. Then write a second version that also replaces the missing values with a zero, and add a sentence explaining why doing this would be a bad idea if we intend to compute the average exam score.
  3. A short explanation of the difference between a null and a NaN, with an example of code that would produce each.
  4. The code that adds a new column holding each student's name in uppercase.
  5. A short explanation, in your own words, of what an expression is and why the same expression c.gpa > 3.5 can be handed to both .filter() and .select().
