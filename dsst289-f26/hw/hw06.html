Assume you have a dataset loaded into Python called students, with columns named name, major, year, gpa, and study_hours, the last of which records the number of hours each student studies in a typical week. Hand write the following.

  1. The three components that the reading says we must specify in order to describe a layer of a plot, along with a sentence about each in your own words.
  2. The code that produces a scatter plot of study_hours and gpa, along with a sentence explaining which of the two variables you put on the x-axis and why.
  3. A sketch, drawn by hand, of what you expect that plot to look like: label the axes, mark roughly where the values start and stop on each one, and draw a cloud of points showing the relationship you would expect to find.
  4. A revised version of the code from part (2) that makes the same plot using only the students who are majoring in History.
  5. A list of three things that plotnine will decide for us in this plot even though we never mention them in the code.
