Assume you have a dataset loaded into Python called students regarding all of the students in our data science class. There are columns called name, major, year, and gpa. Hand write the following, writing each one as its own chain of methods that follows the formatting conventions from the reading.

  1. The code to select just the row of data associated with you.
  2. The code to select the five students with the lowest GPA.
  3. The code to select every History major whose GPA is at least 3.5.
  4. The code that keeps only the students majoring in History, Rhetoric, or Music and then returns just their name and gpa columns.

Solutions

1. Pull out the one row that describes you.

(
    students
    .filter(c.name == "Taylor Arnold")
)

Your own name goes inside the quotes. Testing for equality takes a double equals sign; a single = assigns a value and will not work here.

2. The five students with the lowest GPA.

(
    students
    .sort(c.gpa)
    .head(n=5)
)

A sort runs from smallest to largest unless you say otherwise, so the lowest GPAs land on top and .head takes the first five of them. Adding descending=True would hand back the five highest instead.

3. Every History major with a GPA of at least 3.5.

(
    students
    .filter((c.major == "History") & (c.gpa >= 3.5))
)

The two conditions are joined with &, and each one sits in its own parentheses. "At least 3.5" is >= rather than >, so a student sitting exactly at 3.5 stays in. Two separate .filter steps, one per condition, give the same rows and are also correct. The single filter makes a shorter chain.

4. Keep the History, Rhetoric, and Music majors, then return only their names and GPAs.

(
    students
    .filter(c.major.is_in(["History", "Rhetoric", "Music"]))
    .select(c.name, c.gpa)
)

The three majors go in square brackets inside .is_in, which is shorter and easier to read than three equality tests strung together with |. The filter has to come first. Selecting first would throw away the major column, and the filter would then have no column to test.

Each of the four answers is wrapped in its own pair of parentheses, starts with the dataset name on its own line, and indents each method four spaces. These questions ask for that formatting, so write it out even when the chain is a single method long.
