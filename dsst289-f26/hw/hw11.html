As in the previous homework, assume you have two datasets loaded into Python: students, with one row for each student and columns named name, major, year, gpa, and study_hours; and semesters, with one row for each student in each semester they have been enrolled and columns named name, semester, and gpa. Hand write the following.

  1. The code that adds a column to students giving each student's rank by GPA within their own major, with a rank of one going to the highest GPA in the major.
  2. The code that sorts the students from the most study hours to the fewest and computes, for each student, the percentage of the class's total study hours accounted for by that student and everyone above them, followed by a sentence explaining the different jobs done by the two sums in your expression.
  3. The code that adds a column to semesters holding a smoothed version of each student's GPA, computed as the average of that semester and the two before it, along with a sentence saying which rows come back as missing values and why.
  4. For each of the two questions below, say whether you would answer it with .group_by and .agg or with .over, explain why in a sentence, and write the code: (a) which major has the highest average GPA, and (b) which students have a GPA above the average for their own major.
  5. The code that uses semesters to draw a line plot, one line per student, showing how each student's GPA compares over time to the average GPA of every student in that same semester.

Solutions

1. Add each student's rank by GPA within their own major, with rank one going to the highest GPA.

(
    students
    .with_columns(
        gpa_rank = c.gpa.rank(descending=True).over(c.major)
    )
)

descending=True gives rank one to the largest value, and .over(c.major) starts the ranking over within each major. The rows do not need to be sorted first, because .rank() works from the values themselves.

2. Sort the students from most to fewest study hours and compute the running percentage of the class's total study hours. Explain the two sums.

(
    students
    .sort(c.study_hours, descending=True)
    .with_columns(
        cum_share = c.study_hours.cum_sum() / c.study_hours.sum() * 100
    )
)

.cum_sum() is a running total that grows on every row, while .sum() is the fixed total for the whole class, the same number on every row. Dividing the first by the second gives the share of all study hours reached so far. The sort has to come first, since the running total adds up rows in the order they appear.

3. Add a smoothed GPA to semesters that averages each semester with the two before it, and say which rows come back missing.

(
    semesters
    .sort(c.name, c.semester)
    .with_columns(
        gpa_smooth = c.gpa.rolling_mean(window_size=3).over(c.name)
    )
)

The first two semesters of each student come back missing, because they do not yet have three semesters in their window. The .over(c.name) makes this happen for every student. Without it, the window would slide across the boundary between students, and a student's first semesters would be averaged with the last semesters of the student sorted before them. If a semester's GPA is itself missing, the windows that include it also come back missing.

4. Choose between .group_by with .agg and .over for two questions, explain the choice, and write the code.

(a) Which major has the highest average GPA?

This needs .group_by and .agg, because the answer is about majors, so
the result should have one row for each major.

(
    students
    .group_by(c.major)
    .agg(gpa_avg = c.gpa.mean())
    .sort(c.gpa_avg, descending=True)
)

(b) Which students have a GPA above the average for their own major?

This needs .over, because the answer is a list of students, so every
student has to stay in the table to be compared with their major's
average.

(
    students
    .filter(c.gpa > c.gpa.mean().over(c.major))
)

For (a), the major at the top of the sorted table is the answer. Adding .head(n=1) to keep only that row is also fine.

5. Draw a line plot from semesters, one line per student, comparing each student's GPA over time to the average GPA of all students in the same semester.

(
    semesters
    .with_columns(
        gpa_diff = c.gpa - c.gpa.mean().over(c.semester)
    )
    .ggplot(aes(c.semester, c.gpa_diff, color=c.name))
    .geom_line()
)

This window groups by semester rather than by student, so each row gets the average GPA of everyone enrolled that semester. A value of gpa_diff above zero means the student did better than that semester's average. The plot needs one point per student per semester, which is why it uses .over instead of .agg. Several answers work here. Another good one plots the ratio c.gpa / c.gpa.mean().over(c.semester), where one means the student matches the average.
