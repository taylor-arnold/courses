On a sheet of paper, hand write the following.

  1. Code that creates a variable named age_years holding your age in years, followed by a second line that uses this variable to compute your approximate age in days.
  2. The lines of code we will put at the top of nearly every script this semester to load Polars, plotnine, and the functions in funs.py.
  3. Two different calls to the round function that round 2.71828 to two digits, one using positional arguments and one using named arguments.
  4. Three variable names that follow the conventions described in the reading and two that do not, with a short note about what is wrong with each of the second set.

Solutions

1. Store your age in years, then use that variable to work out your age in days.

age_years = 21
age_days = age_years * 365

2. The import lines that start almost every script this semester.

import polars as pl
from plotnine import ggplot, aes
from polars import col as c

import funs

3. Round 2.71828 to two digits two ways, once with positional arguments and once with named arguments.

round(2.71828, 2)
round(number=2.71828, ndigits=2)

4. Since you choose your own names, there are many valid answers. A good response gives three names that use only lowercase letters, underscores, and numbers, that start with a letter or an underscore, and that avoid capital letters, along with two that break one of those rules and a note on the problem. One example:

Follow the conventions:
    age_years
    total_calories
    _count

Break the conventions:
    2nd_score   (starts with a number, which is not allowed)
    TotalScore  (uses capital letters; the reading recommends only
                 lowercase letters and underscores)
