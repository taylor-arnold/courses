On a sheet of paper, hand write the following.

  1. Code that creates a variable named age_years holding your age in years, followed by a second line that uses this variable to compute your approximate age in days.
  2. The lines of code we will put at the top of nearly every script this semester to load Polars, plotnine, and the functions in funs.py.
  3. Two different calls to the round function that round 2.71828 to two digits, one using positional arguments and one using named arguments.
  4. Three variable names that follow the conventions described in the reading and two that do not, with a short note about what is wrong with each of the second set.
