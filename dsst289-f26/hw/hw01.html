On a sheet of paper, hand write the following.

  1. Code that creates a variable named age_years holding your age in years, followed by a second line that uses this variable to compute your approximate age in days.
  2. The lines of code we will put at the top of nearly every script this semester to load Polars, plotnine, and the functions in funs.py.
  3. Two different calls to the round function that round 2.71828 to two digits, one using positional arguments and one using named arguments.
  4. Three variable names that follow the conventions described in the reading and two that do not, with a short note about what is wrong with each of the second set.

Solutions

Write these out by hand; the point of the assignment is the writing, not the running. Questions 1 and 4 ask about you, so your page will not match mine word for word.

1. Store your age in a variable, then use that variable to work out roughly how many days old you are.

age_years = 20
age_days = age_years * 365

Your own age goes on the first line. The second line has to mention age_years: if you wrote age_days = 20 * 365 you did the arithmetic yourself and never used the variable, which was the whole point.

2. The imports that start nearly every script this semester.

import polars as pl
from plotnine import ggplot, aes
from polars import col as c

import funs

All four lines matter, and so does the spelling of the aliases. We type pl and c constantly, so they have to be exactly these.

3. Round 2.71828 to two digits, once with positional arguments and once with named arguments.

round(2.71828, 2)

round(number=2.71828, ndigits=2)

Both return 2.72. The names number and ndigits are the ones round actually uses; help(round) is how you would look them up.

4. Three variable names that follow the conventions from the reading, and two that break them.

Lots of names work here. One good set:

Good:
    age_years
    total_fat
    mean_rating_2024

Bad:
    2nd_try     starts with a number, so Python will not accept it at all
    Total Fat   has a space in it, and capital letters we would have to
                remember later; total_fat is the name we want

The conventions are: start with a letter or an underscore, use only lowercase letters, numbers, and underscores after that, and separate words with underscores rather than capital letters. So totalFat also belongs in the second group, since it runs afoul of the last rule even though Python would happily accept it.
