The first exam consists of 10 questions. All involve hand-writting short code blocks concerning the RVA flights datasets: rva, airport, and airline. It is very similar in style to Exam 1. You should generally be comfortable with the material in Chapter 2, Chapter 3 and Chapter 4. However, only those mentioned below along with everything list on Exam 1, will be required for this exam.

  1. Use .group_by along with .agg to take the mean of one or more variables. You should also be able to add a count by including pl.len().
  2. Creating a scatterplot with geom_point, which may have variable or fixed color or size.
  3. Adding text to a plot with geom_text, which may have variable or fixed color or size. No need to build in nudging (it is not possible without seeing the full dataset to get the scale correct anyway).
  4. Building a histogram or boxplot using the appropriate geometries. You do not need to flip the axes or order the categories. For each of these you can use the default bins, colors, offsets and fill values provided by plotnine.
  5. Changing the scale of a plot by adding scale_x_log10, scale_y_log10, scale_color_cmap_d or scale_size_area. You do not need to know how to set the breaks manually.
  6. Know how to combine two datasets using .join where there may be multiple keys or the keys may have different names in the two tables. The datasets here have no missing relations, so everyhing can use the default join type (inner).
  7. We will not have the pivot, unpivot or explode methods on the exam.

Many questions will require putting multiple functions together in a method chain. All can be done with at most three methods and three graphics commands. Your code should follow the class formatting rules of putting parantheses around the whole block, starting with the DataFrame, and having each method on its own line. You should be familiar with the other formatting rules regarding spacing and names, but these will not be graded on the exam.

Practice Exam Questions and Answers

1. Compute the average runtime of the films by year. Include a count of the number of films in each year in the output table.

(
    movie
    .group_by(c.year)
    .agg(
        avg_runtime = c.runtime.mean(),
        count = pl.len()
    )
)

2. Create a scatterplot where the points are years, where the x-axis gives the average rating, the y-axis the average gross (amount of money it made) and all the points are in the color "yellow".

(
    movie
    .group_by(c.year)
    .agg(
       avg_rating = c.rating.mean(),
       avg_gross = c.gross.mean()
    )
    .pipe(ggplot, aes("avg_rating", "avg_gross"))
    + geom_point(color = "yellow")
)

3. Pretend there exists a column called budget. Create a scatterplot of all the films with budget on the x-axis and gross on the y-axis. Have both axes on a logarithmic scale.

(
    movie
    .pipe(ggplot, aes("budget", "gross"))
    + geom_point()
    + scale_x_log10()
    + scale_y_log10()
)

4. Create a boxplot showing the mpa code on the x-axis and the runtime on the y-axis, but only use data from 1985 and after.

(
   movie
   .filter(c.year >= 1985)
   .pipe(ggplot, aes("mpa", "runtime"))
   + geom_boxplot()
)

5. Join the genre table to the movies data, and count the number of movies in each genre. Hint: need to join on year and title.

# This is the better approach because year + title are the primary
# key in movie and foreign key in genre, so we join genre on the
# left and movie on the right.
(
    genre
    .join(movie, on=[c.year, c.title])
    .group_by(c.genre)
    .agg(count = pl.len())
)

# This is also fine, will run without an error, and will get full
# credit on the exam.
(
    movie
    .join(genre, on=[c.year, c.title])
    .group_by(c.genre)
    .agg(count = pl.len())
)

6. Create a text plot with the films from the year of your birth, with rating on the x-axis and gross on the y-axis and the label given by the film title.

(
    movie
    .filter(c.year == 1985)
    .pipe(ggplot, aes("rating", "gross"))
    + geom_text(aes(label="title"))
)
