Exam II Study Guide

The first exam consists of 10 questions. All involve hand-writting short code blocks concerning the RVA flights datasets: rva, airport, and airline. It is very similar in style to Exam 1. You should generally be comfortable with the material in Chapter 2, Chapter 3 and Chapter 4. However, only those mentioned below along with everything list on Exam 1, will be required for this exam.

  1. Creating a scatterplot with geom_point, which may have variable or fixed color or size.
  2. Adding text to a plot with geom_text, which may have variable or fixed color or size. No need to build in nudging (it is not possible without seeing the full dataset to get the scale correct anyway).
  3. Building a histogram or boxplot using the appropriate geometries. You do not need to flip the axes or order the categories. For each of these you can use the default bins, colors, offsets and fill values provided by plotnine.
  4. Changing the scale of a plot by adding scale_x_log10, scale_y_log10, scale_color_cmap_d or scale_size_area. You do not need to know how to set the breaks manually.
  5. Know how to combine two datasets using .join where there may be multiple keys or the keys may have different names in the two tables. The datasets here have no missing relations, so everyhing can use the default join type (inner).
  6. Be able to use .pivot with the parameters index, on, and values. The unpivot method will not be on the exam.
  7. The explode method should be on the exam, but there are no columns to explode here, so there will not be any questions on it.

Many questions will require putting multiple functions together in a method chain. All can be done with at most three methods and three graphics commands. Your code should follow the class formatting rules of putting parantheses around the whole block, starting with the DataFrame, and having each method on its own line. You should be familiar with the other formatting rules regarding spacing and names, but these will not be graded on the exam.
