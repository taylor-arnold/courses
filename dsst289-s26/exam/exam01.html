The first exam consists of 10 questions. You will have the whole class period to finish them but should not need more than 30 minutes. More than the others, this exam is focused on being able to write short Python code related to what we are doing in class. There are seven questions that require writing some code relative to a dataset that I will give you the first few rows of:

  1. Produce a scatter plot with one variable on the x-axis and another on the y-axis.
  2. Modify the scatter plot from the first question to make the points a different fixed size and color.
  3. Modify the scatter plot to make the color change with one of the other variables in the dataset. No need to add a custom scale.
  4. Select the rows of a dataset where one of the variable is greater than some fixed value.
  5. Add a column to the dataset by changing the units of measurement of one column (for example, feet to inches). I will give the units of conversion.
  6. Sort the dataset by one of the columns in descending order.
  7. Select a subset of the columns from a dataset using the list notation given in Notebook3a.

There are also three conceptional questions:

  1. I will give you a scatter plot with text labels and describe the names of the variables in the plot. You will need to describe in words what features are associated with the x, y, label, size, shape, and color aesthetics.
  2. I will give you a second scatter plot with just a few points. You will need to create a tabular dataset approximating what data would produce this plot.
  3. I will describe 10 different types of information we might record in a dataset. You will need to describe whether the data should be an integer, float, or string and give an example of the data type. It will either be very clear what the answer is or I will give credit for any of the possible values (mostly this concerns whether we have an integer or a float).
