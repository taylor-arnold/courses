The first exam consists of 10 questions. All involve hand-writting short code blocks concerning the food dataset. You should generally be comfortable with the material in Chapter 2, but only the following functions will be needed for the exam:

  1. Using .sort to sort the data by ascending or descending order.
  2. Selecting a certain number of rows using .head or .tail.
  3. Using .group_by to apply .head or .tail to select a certain number of rows (at most) from each group.
  4. Selecting rows using .filter based on a numeric variable being less than, less than or equal to, equal to, greater than or equal to, or greater than a fixed value.
  5. Selecting rows using .filter based on a string variable being equal to a specific value.
  6. Selecting rows using .filter and .is_in to select rows where a string column is in a set of values.
  7. Using .with_columns to create a new variable based on arthimetic manipulation of two or more other columns.
  8. Using the agg function with .group_by to compute data aggregates using the column methods .mean, .min, .max, .first, or .last.
  9. Using the pl.len function within .agg.

Many questions will require putting multiple functions together in a method chain. All can be done with at most three methods. Your code should follow the class formatting rules of putting parantheses around the whole block, starting with the DataFrame, and having each method on its own line. You should be familiar with the other formatting rules regarding spacing and names, but these will not be graded on the exam.
