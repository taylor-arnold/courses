Assume that you have a dataset loaded into Python called students regarding all of the students in our data science class. There are columns called name, major, gpa, and major_gpa. Hand write the following: (1) the code to select the student with the best major GPA within each major and (2) the code to create a variable gpa_diff as the difference between the GPA and major GPA, and (3) using the gpa_diff, selecting the student with the largest overall difference.
