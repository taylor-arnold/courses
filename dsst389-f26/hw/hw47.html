This reading treats images as arrays of numbers and computes brightness and color from the pixels directly. The first two questions ask you to do that arithmetic by hand.

  1. OpenCV reads the following 2×2 image, printed exactly as it would appear in Python:

    [[[255, 0, 0], [0, 0, 255]],
     [[0, 255, 0], [255, 255, 255]]]

    Give the shape of the array, name the color of each of the four pixels, and compute the mean pixel value of the whole image.
  2. For a pixel whose RGB values scaled to 0 to 1 are R = 0.2, G = 0.6, B = 0.4, compute M, m, the chroma C, and then the hue, saturation, and value using the formulas in the reading.
  3. Say what happens to the hue formula for a pixel with R = G = B = 0.5, and why the answer is not meaningful.
  4. Given that the darkest images have black backgrounds and the brightest have white ones, say what the brightness column is actually a measurement of.
  5. The images with the most yellow pixels are largely hummingbirds shot against yellow-green foliage, so say what would go wrong if you used the color-proportion columns to predict a bird's species.
