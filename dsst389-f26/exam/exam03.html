Exam III Study Guide

[← back]

The third exam is 75 minutes. It has twelve short questions spread across four tasks, labeled A through D. It is shorter than the second exam because it covers only four class days. As on the first two exams, every task gives you a small dataset — an edge list, a list of citing pages, a pixel array, a handful of vectors — together with the code that runs on it, and your job is to say what comes out. As on the second exam, every question is either multiple choice or fill-in-the-blank, and you write your answers directly on the exam:

  • Multiple choice (seven questions). Four options; circle the one best answer. The right answer is always clearly right, but at least one of the others will look plausible if you are not careful: it is usually the answer you get by making one of the mistakes we have discussed all unit, such as reading a BGR array as RGB, dividing by the number of pixels instead of the number of values, or trusting where a node is drawn over which edges it has.
  • Fill in the blank (five questions). A number, a label, a row count, or a short piece of text, with one correct answer. Several questions have two or more blanks. Numbers should be exact or rounded to two decimal places.

You do not need to memorize any function names, arguments, or formulas. There is no reference sheet for this exam. Instead, anything you need is given with the question itself: the definitions of closeness and betweenness, what co-citation means, the BGR channel order, and the fact that the dot product of unit vectors is their cosine similarity are all stated where they are used. What you do need is to understand the ideas well enough to apply them to the data in front of you. The network is drawn for you; bring a pencil to sketch on it as you work, and bring a calculator.

The exam covers Chapter 16 and Chapter 17, along with Homeworks 45 through 48.

What You Need To Know

The exam has four tasks. Each one uses a specific kind of data and tests a specific, short list of ideas. The lists below are complete: if an idea is not here, it is not on the exam.

Task A. Network metrics (four questions). An undirected network given as an edge list, with a drawing of the same network beside it.

  1. The degree of a node is its number of neighbors. A component is a set of nodes that can all reach one another by following edges. Read the degree of a named node off the drawing and count the components. The node table from DSNetwork.process has a component column that labels each node's component, but no question depends on which number a component is given.
  2. The distance between two nodes is the number of edges on the shortest path between them, not the length of the line on the page. Closeness is the sum of the reciprocals of a node's distances to every other node in its component. Compute it for a named node.
  3. Betweenness adds up, over every pair of other nodes, the fraction of their shortest paths that pass through a node. On the exam every pair that matters has a single shortest path, so betweenness is a count: find the pairs whose shortest path has to cross a node and count them.
  4. A bridge between two dense groups can have the lowest degree in its component and the highest betweenness. Know why, and know that where a node is drawn plays no part in any of these scores.
  5. The cluster column splits a component into groups with many edges inside them. For a node that sits symmetrically between two groups, the label it gets is an arbitrary tiebreak, printed with the same confidence as every other label.

Eigenvector centrality, the internals of the clustering algorithm, the x and y layout columns, and splitting credit between tied shortest paths are not on the exam.

Task B. Co-citation (two questions). A short table of outside pages and the authors each one links to.

  1. Two authors are joined by a co-citation edge whenever some third page links to both of them, and the edge's count is the number of such pages. A page that links to three authors contributes three pairs. Write the edge list, count its rows, and give the count for a named pair.
  2. Know what a missing pair means: no citing page links to both authors. It says nothing about whether the two authors' own pages link to each other.

Directed networks (in-degree and out-degree), distance networks, and nearest neighbor networks are not on the exam.

Task C. Images as arrays (three questions). A tiny image printed as an OpenCV array whose channels are all 0 or 255.

  1. The shape is (height, width, channels). img.mean(), the brightness the chapter records, averages over every number in the array, channels included, so a 2 × 3 image averages 18 numbers, not 6.
  2. OpenCV stores channels in BGR order: [255, 0, 0] is blue and [0, 0, 255] is red. Name the color of each pixel, and count how many would be misnamed by someone who read the array as RGB (black, white, and green read the same either way). Reordering channels changes the names of colors but not the mean.
  3. A whole-image statistic such as brightness describes the entire frame, background and lighting included, not just the bird. Pick the statement that explains a pattern in brightness across species.

HSV, the color proportions from compute_colors, and writing OpenCV code are not on the exam.

Task D. Embeddings and zero-shot classification (three questions). A few image vectors and category text vectors in three dimensions, all of unit length.

  1. For vectors of unit length the dot product is the cosine similarity, so a larger dot product means a closer match. Compute the dot product of an image with each category and give the label with the largest one.
  2. Zero-shot classification is an argmax over the list of categories you supply. It always returns one of them, even when the true category is missing from the list, and adding a category can change an image's label.
  3. Zero-shot classification needs a model such as SigLIP that puts images and text in one shared space. ViT embeds only images, so even though its embeddings separate the species well, there are no text vectors to compare against. Both models give dense vectors, unlike TF-IDF.

The architecture and training of ViT or SigLIP, UMAP, and the angle distance (the arccos) are not on the exam.

Practice Questions

Every question below is in the exam's own format and uses a parallel dataset. Every question on the exam has a twin here, and there are a few extra practice questions beyond that, so this set is a little longer than the exam itself. Work through all of them with the data in front of you and a calculator, as you will on the day; the answers follow each question. If you can do these, you can do the exam.

The code node, edge, G = DSNetwork.process(edges, directed=False) returns a node table with one row per node. A component is a set of nodes that can all reach one another by following edges, and the degree of a node is its number of neighbors. The distance between two nodes is the number of edges on the shortest path between them. The two centrality scores below are computed separately within each component.

  • Closeness of a node: the sum of the reciprocals of its distances to every other node in its component.
  • Betweenness of a node: for every pair of other nodes, the fraction of the shortest paths between them that pass through this node, added up over all pairs.

1. (Fill in the blank.) The degree of S is ________, the degree of R is ________, and the network has ________ components.

2;  3;  2.

    degree:  P 2   Q 2   R 3   S 2   T 3   U 2   V 2   W 1   X 1

The two components are the seven nodes {P, Q, R, S, T, U, V} and the pair
{W, X}. Note that S, the node holding the two triangles together, has one of
the lowest degrees in its component despite sitting in the middle of it.

2. (Fill in the blank.) The closeness of S is ________, and the betweenness of S is ________.

4.00;  9.

From S, R and T are one hop away and P, Q, U, V are two hops away:

    close(S) = 1/1 + 1/1 + 1/2 + 1/2 + 1/2 + 1/2 = 4.00

Every path from the left triangle {P, Q, R} to the right one {T, U, V} has to
cross S, and each of those 3 x 3 = 9 pairs has a single shortest path. No
other pair needs S, so

    betweenness(S) = 9

W and X play no part in either score: they are in a different component, and
the distance to them is not large but undefined.

3. (Fill in the blank.) The closeness of P is ________, and the closeness of R is ________.

3.33;  4.17.

    From P:  Q = 1, R = 1, S = 2, T = 3, U = 4, V = 4
    close(P) = 1 + 1 + 1/2 + 1/3 + 1/4 + 1/4 = 3.33

    From R:  P = 1, Q = 1, S = 1, T = 2, U = 3, V = 3
    close(R) = 1 + 1 + 1 + 1/2 + 1/3 + 1/3 = 4.17

R edges out S (4.17 to 4.00): three neighbors at distance 1 are worth more than
S's position in the middle. The reciprocal makes being far from something cheap
and being adjacent to it valuable. Adding up the distances instead of their
reciprocals (14 for P) is the tempting wrong answer.

4. (Multiple choice.) S has one of the lowest degrees in its component but the highest betweenness. Which statement best explains this?

  1. The score must be an error: a node with only two neighbors can lie on at most one shortest path.
  2. S is a bridge: every shortest path between the two triangles passes through it, so it is unavoidable even though it has only two neighbors.
  3. S has the highest closeness in its component, and betweenness always ranks nodes in the same order as closeness.
  4. Betweenness rewards the node drawn nearest the middle of the picture, and S is drawn in the middle.
(B). Betweenness finds the nodes that are not popular but are unavoidable.
(D) is false because the drawing plays no part in the computation; move S
anywhere on the page and its score is unchanged. (C) is false twice over: R and
T have higher closeness (4.17) than S (4.00), as question 3 showed, and the
two scores need not agree. (A) confuses neighbors with paths: S's two
neighbors are the two ends of nine different shortest paths.

5. (Multiple choice.) The node table below is what DSNetwork.process(edges, directed=False) returns for this network, with the layout columns x and y omitted. The cluster column splits the seven-node component into {P, Q, R} and {S, T, U, V}. Which statement best describes the placement of S?

idcomponentcomponent_sizeclusterdegreebetweenclose
P17020.03.33
Q17020.03.33
R17038.04.17
S17129.04.00
T17138.04.17
U17120.03.33
V17120.03.33
W22210.01.00
X22210.01.00
  1. It shows that S is more strongly attached to the right triangle, since T has a higher degree than R.
  2. It is essentially arbitrary: the network is symmetric, S is attached equally to both triangles, and the algorithm had to put it somewhere.
  3. It is correct, because the edge S–T comes after the edge R–S in the edge list.
  4. It is an error: S should have a cluster of its own, because it has the highest betweenness.
(B). Swap P with U, Q with V, and R with T, and you get the identical network
back, with S mapped to itself. S is one edge from R and one edge from T and
belongs to neither triangle more than the other. R and T both have degree 3,
so (A) is false.

A cluster label is an OUTPUT OF AN ALGORITHM, not a property of a node. For
nodes deep inside a dense group the label is stable and means something. For a
node on a boundary it can be an arbitrary tiebreak, and nothing in the node
table tells the two cases apart: S's label is printed with exactly the same
confidence as P's.

6. (Fill in the blank.) Suppose the edge R–S is deleted. The network then has ________ components, the largest has ________ nodes, and the betweenness of S becomes ________.

3;  4;  0.

The pieces are {S, T, U, V} (4 nodes), {P, Q, R} (3), and {W, X} (2). S stays
attached to the right triangle through S–T, but it is now a dead end: no
shortest path between two other nodes passes through it. A node's betweenness
depends on the whole network, not just on its own edges.

Task B. Co-citation

In a co-citation network, two authors are joined by an edge whenever some third page links to both of them. The count of an edge is the number of such pages. Five outside pages link to the authors P, Q, R, and S as follows.

citing pagelinks to
page 1P, Q, R
page 2P, Q
page 3Q, R
page 4R, S
page 5P, S

7. (Fill in the blank.) The co-citation edge list has ________ rows. The count for the pair P–Q is ________, and for the pair Q–R is ________.

5;  2;  2.

Go through the pages and tally every pair:

    page 1 (P,Q,R)  ->  P–Q, P–R, Q–R
    page 2 (P,Q)    ->  P–Q
    page 3 (Q,R)    ->  Q–R
    page 4 (R,S)    ->  R–S
    page 5 (P,S)    ->  P–S

    doc_id  doc_id_out  count
    P       Q               2      (pages 1, 2)
    P       R               1      (page 1)
    P       S               1      (page 5)
    Q       R               2      (pages 1, 3)
    R       S               1      (page 4)

Page 1 links to three authors and so contributes three pairs. Counting one row
per page-and-pair (7) instead of one row per pair is the tempting wrong answer.

8. (Multiple choice.) The pair Q–S does not appear in the co-citation edge list. What does that tell you?

  1. The pages for Q and S do not link to each other.
  2. Q and S were filtered out for having too few citing pages.
  3. None of the five citing pages links to both Q and S.
  4. Q and S are in different components of the co-citation network.
(C). A co-citation edge is about a THIRD page, not about Q and S themselves.
Q and S could link to each other directly and the pair would still be absent,
since co-citation never looks at their own links, which rules out (A). (D) is
false: Q and S are in the same component, through R or P.

9. (Fill in the blank.) In the co-citation network, the degree of P is ________, and the sum of the counts on P's edges is ________.

3;  4.

P shares a citing page with Q (count 2), R (count 1), and S (count 1). Degree
counts neighbors, so it is 3; the counts add up to 4. The two numbers answer
different questions: how many authors P keeps company with, versus how many
times it does.

Task C. Images as Arrays

OpenCV reads a tiny image and prints the array below. OpenCV stores an image as an array of shape (height, width, channels), with values from 0 to 255, and it stores the three channels in BGR order: blue, then green, then red. Every channel here is 0 or 255, so each pixel is red, green, blue, black, or white.

img = [[[  0,   0, 255], [255,   0,   0]],
       [[  0, 255,   0], [255, 255, 255]]]

10. (Fill in the blank.) img.shape is ________. img.mean(), the brightness the chapter would record, averages over ________ numbers and returns ________.

(2, 2, 3);  12;  127.5.

Two rows of pixels, two columns, three channels. The mean is over ALL TWELVE
NUMBERS, not the four pixels:

    255 + 255 + 255 + 765 = 1530
    1530 / 12 = 127.5

Dividing by the 4 pixels instead gives 382.5, a number larger than any single
value in the array can be, which is a sign that something has gone wrong.

11. (Multiple choice.) How many of the four pixels would be given the wrong color name by someone who read the array as RGB?

  1. 0
  2. 1
  3. 2
  4. 4
(C). Read the triples as blue, green, red:

    [0,0] = [  0,   0, 255]   B=0   G=0   R=255   -> RED
    [0,1] = [255,   0,   0]   B=255 G=0   R=0     -> BLUE
    [1,0] = [  0, 255,   0]   B=0   G=255 R=0     -> GREEN
    [1,1] = [255, 255, 255]   equal in all three  -> WHITE

An RGB reading swaps the first two. Green and white read the same either way,
which is what makes the mistake so easy to miss: half the pixels come out
right.

12. (Multiple choice.) Computing img.mean() for every photo in the birds dataset, the course found that ostrich photos tend to be the brightest. What is the most likely explanation?

  1. Ostrich feathers are white, and white feathers produce the largest values in all three channels.
  2. Ostriches are larger than the other birds, so they fill more of the frame.
  3. The ostrich photos were read in RGB order instead of BGR.
  4. Ostriches tend to be photographed outdoors in bright, open settings, and the mean averages over the whole frame, background included.
(D). A pixel statistic describes the whole photograph: subject, background,
and lighting mixed together. The same bird photographed against a white
background scores higher than it does against a dark one. (A) is tempting, but
the bird is only part of the frame, and much of an ostrich is dark. (C) cannot be right: as the next
question shows, channel order changes the names of colors, not the numbers
being averaged.

13. (Multiple choice.) A classmate reverses the channel order of the array above from BGR to RGB before calling img.mean(). What does the mean become?

  1. It is unchanged at 127.5.
  2. It falls, because the red pixel's 255 moves to a different channel.
  3. It rises, because RGB order puts the brightest channel first.
  4. It cannot be computed until the pixels are also reordered.
(A). Reversing the channel order moves the numbers around inside each pixel but
changes none of them, and a mean of all twelve numbers does not care what order
they are in. Channel order matters when you NAME a color, not when you average
it: the red and blue pixels trade names, and the mean stays at 127.5.

Task D. Embeddings and Zero-Shot Classification

Suppose SigLIP embedded images and text into a space with only three dimensions. Two images and three category descriptions embed to the following vectors, all of unit length. For vectors of unit length, the dot product is the cosine similarity from Chapter 15, so a larger dot product means a closer match. To classify an image zero-shot, compute its dot product with each category's text vector and give it the label with the largest dot product.

img1    = (0.6, 0.8, 0.0)          canary  = (1.0, 0.0, 0.0)
img2    = (0.0, 0.8, 0.6)          peacock = (0.0, 0.0, 1.0)
                                   robin   = (0.8, 0.6, 0.0)

14. (Fill in the blank.) The dot product of img1 with canary is ________, with peacock is ________, and with robin is ________, so img1 is labeled ________.

0.60;  0.00;  0.96;  robin.

    img1 . canary  = 0.6(1.0) + 0.8(0.0) + 0.0(0.0) = 0.60
    img1 . peacock = 0.6(0.0) + 0.8(0.0) + 0.0(1.0) = 0.00
    img1 . robin   = 0.6(0.8) + 0.8(0.6) + 0.0(0.0) = 0.48 + 0.48 = 0.96

The classifier is nothing more than "take the largest of these numbers."

15. (Multiple choice.) Suppose img2 is actually a photo of a jay, which is not one of the three categories. What does the zero-shot classifier return for it?

  1. "jay", because SigLIP was trained on far more categories than the three supplied.
  2. "peacock", the closest of the categories supplied, with no warning that the true answer is missing.
  3. Nothing (a null), because no dot product is close enough to 1.
  4. An error, because the image does not match any of the categories.
(B). img2 scores 0.00 with canary, 0.60 with peacock, and 0.48 with robin.
Zero-shot classification is an argmax over the candidate list you supplied. It
always returns one of those labels, however poor the best match is, and it
cannot name a category it was not given, whatever the model saw in training.

16. (Multiple choice.) The chapter also embeds the bird photos with ViT, whose embeddings separate the ten species almost perfectly in a UMAP plot. What does SigLIP provide that zero-shot classification needs and ViT does not?

  1. Dense embeddings, in which nearly every number is non-zero.
  2. A training set that included the ten bird species.
  3. A single space shared by images and text, so an image vector can be compared with the vector of a category's name.
  4. Embeddings of exactly 768 numbers.
(C). Zero-shot classification compares an image vector with the vector of a
category's NAME, which requires images and text to live in one shared space.
ViT embeds only images, so there is nothing to compare against. (A) is true of
SigLIP but also of ViT: both give dense vectors, unlike TF-IDF. (B) misses the
point: the UMAP plot shows that ViT's embeddings describe the birds well
without knowing their names.

17. (Fill in the blank.) Suppose a fourth category, jay = (0.0, 0.6, 0.8), is added to the three above. The label of img2 becomes ________, with a dot product of ________.

jay;  0.96.

    img2 . jay = 0.0(0.0) + 0.8(0.6) + 0.6(0.8) = 0.48 + 0.48 = 0.96

That beats peacock's 0.60, so img2's label changes even though img2 itself did
not. Add a candidate and a label can change; leave the right one out and the
classifier returns the closest wrong one. img1's label is unaffected:
img1 . jay = 0.8(0.6) = 0.48, still below robin's 0.96.
