We will introduce the final project in class on October 14th. You will define a population of 75 to 250 Wikipedia pages, collect it yourself through the APIs, document it, and analyze it with the temporal, textual, and network methods from the second half of the course. Read the project description before Homework 14, which is a two-week assignment due at Workshop I on October 28th. Start thinking about your population early: it is locked at the workshop and everything else follows from it. There is no final exam.
