The first exam consists of 10 questions. All involve hand-writting short code blocks concerning the country and border datasets. You should generally be comfortable with the material in Chapter 2, Chapter 3 and Chapter 4. However, only the following functions will be needed for the exam:

  1. Creating a scatterplot with geom_point, which may have variable or fixed color or size.
  2. Adding text to a plot with geom_text, which may have variable or fixed color or size. No need to build in nudging (it is not possible without seeing the full dataset to get the scale correct anyway).
  3. Changing the scale of a plot by adding scale_x_log10, scale_y_log10, scale_color_cmap_d or scale_size_area. You do not need to know how to set the breaks manually.
  4. Using .sort to sort the data by ascending or descending order.
  5. Selecting a certain number of rows using .head or .tail.
  6. Using .group_by to apply .head or .tail to select a certain number of rows (at most) from each group.
  7. Selecting rows using .filter based on a numeric variable being less than, less than or equal to, equal to, greater than or equal to, or greater than a fixed value.
  8. Selecting rows using .filter based on a string variable being equal to a specific value.
  9. Selecting rows using .filter and .is_in to select rows where a string column is in a set of values.
  10. Using .with_columns to create a new variable based on arthimetic manipulation of two or more other columns.
  11. Using the agg function with .group_by to compute data aggregates using the column methods .mean, .min, .max, .first, or .last. Also, you should be able to use pl.len within .agg.
  12. Know how to combine two datasets using .join where there may be multiple keys or the keys may have different names in the two tables. The datasets here have no missing relations, so everyhing can use the default join type (inner).

Most questions will require putting multiple functions together in a method chain. All can be done with at most three methods. Your code should follow the class formatting rules of putting parantheses around the whole block, starting with the DataFrame, and having each method on its own line. You should be familiar with the other formatting rules regarding spacing and names, but these will not be graded on the exam.
