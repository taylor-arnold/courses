Treat each of the five documents below as individual documents:

  1. the cat sat on the mat
  2. the dog sat on the rug
  3. the cat and the dog run
  4. the dog sat on the mat
  5. the cat ran on the rug

First step: Write out what the term-frequency matrix (so there should be five rows and a column for each unique term) would look like for these documents, assuming that we include all of the terms. You can write a dot in place of a zero (there are a lot of zeros and this is a common short hand). How would this change based on whether we use the tokens or lemmas?

Second step: Write out the TF-IDF matrix corresponding to the term-frequency matrix you wrote in the first question.
